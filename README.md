# Tony / 唐胜斌

Static personal website adapted from the supplied Valtero HTML template. English is the primary language, with brief Chinese supporting copy.

## Preview locally

From this directory, run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Publishing

The site is ready for GitHub Pages from the repository root. Enable **Settings → Pages → Deploy from a branch → main → /(root)**. The free project address is `https://tony132321.github.io/ve112/`.
